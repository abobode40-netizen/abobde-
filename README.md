2. في الجهة اليمنى (أو أعلى الصفحة على الهاتف) عند قسم **About**، اضغط على علامة الترس ⚙️ (**Edit repository details**).
3. في حقل **Website**، ضع الرابط التالي:
   ```
   https://ais-pre-g5khwdthhv7fn76wsmh27c-370477156971.europe-west2.run.app
   ```
   أو رابط GitHub Pages:
   ```
   https://abobode40-netizen.github.io/bobode40-netizen-mooo/
   ```
4. اضغط على **Save changes**. سيظهر الرابط مباشرة تحت اسم المستودع كزر قابل للنقر يفتح التطبيق فوراً.

## 🌟 مميزات تطبيق جنّة الرحمن

- 📖 **المصحف الشريف كاملاً**: تصفح صفحات مصحف المدينة بدقة عالية، مع علامات الحفظ المرجعية وتفاسير الآيات (الميسر، السعدي، ابن كثير، القرطبي).
- 🎙️ **الاستماع الصوتي المتواصل**: استماع لكامل السور بأصوات كبار القراء (الحصري، المنشاوي، عبد الباسط، العفاسي، المعيقلي، الشاطري، وغيرهم).
- 📿 **غراس الأذكار والسبحة الإلكترونية**: أذكار الصباح والمساء، أذكار الصلاة، أذكار النوم، مع سبحة تفاعلية متطورة ذات اهتزاز وتأثيرات صوتية.
- 🌳 **شجرة العبادات اليومية**: تتبع ومتابعة الصلوات الخمس والسنن الرواتب وقراءة القرآن، مع إمكانية تصدير صورة إنجاز الشجرة اليومية ومشاركتها.
- 🕌 **مواقيت الصلاة الدقيقة**: تحديد أوقات الصلوات بحسب موقعك الجغرافي وحساب الوقت المتبقي لكل صلاة.
- 💡 **ثمار المشايخ ومشكاة النور**: مكتبة من درر وأقوال أئمة وعلماء أهل السنة والجماعة مع ربط تدبري بالآيات القرآنية.
- 🤖 **محرك الذكاء الاصطناعي (Google AI Studio & Gemini)**: استخراج الفوائد والوقفات التدبرية للآيات القرآنية.
- 📱 **تطبيق ويب تقدمي (PWA)**: إمكانية تثبيت الموقع كتطبيق مستقل على أندرويد وiOS والكمبيوتر مع دعم العمل الكامل دون اتصال بالإنترنت (Offline-First).

## 🛠️ التشغيل والتطوير المحلي (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل الخادم في وضع التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build

# تشغيل النسخة الإنتاجية
npm start
```

## 🤝 الجسر بين GitHub و Google AI Studio (Bridge Architecture)

يعمل هذا المستودع كـ **Bridge** يربط بين:
- **GitHub Repository**: إدارة الكود المصدري والتحديثات المستمرة والأرشفة.
- **Google AI Studio Cloud Engine**: تشغيل بيئة المعالجة السحابية وواجهات الـ API للذكاء الاصطناعي وخدمات الـ Full-Stack المباشرة.
- **GitHub Pages / Cloud Run**: توفير روابط عامة (Public) مفتوحة ومتاحة للجميع في أي وقت.
